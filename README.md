# Smart Banking CMS

## Project Overview

Smart Banking CMS is a banking data management and analytics project.

The project contains customer, bank, account and transaction data. SQL was used for database-related work and analysis, while Excel, Power BI and Tableau were used for data analysis and visualization.

## Project Objective

- Manage customer and account data
- Analyze banking transactions
- Perform SQL-based data analysis
- Analyze account balances and transaction activity
- Create interactive dashboards
- Generate useful business insights

## Technologies Used

- MySQL
- SQL
- Microsoft Excel
- Power BI
- Tableau

## Project Data

The project contains:

- 500 Customers
- 500 Accounts
- 1000 Transactions

## Key Analysis

- Account Type Analysis
- Account Status Analysis
- Account Balance Analysis
- Bank-wise Account Analysis
- Bank-wise Balance Analysis
- Credit vs Debit Transaction Analysis
- Monthly Transaction Trends
- Customer Gender Analysis
- Top Accounts by Balance

## Power BI Dashboard

The Power BI dashboard includes:

- Total Customers
- Total Accounts
- Total Balance
- Total Transactions
- Transaction Type Distribution
- Account Type Distribution
- Account Status Distribution
- Monthly Transaction Amount Trend
- Bank-wise Account & Balance Summary
- Interactive filters for Bank, Account Type, Transaction Type and City

## Tableau Dashboard

The Tableau dashboard includes:

- Banking Overview
- Customer Analysis
- Transaction Analysis
