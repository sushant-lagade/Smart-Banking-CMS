Smart Banking CMS

A banking data management and analytics project developed as part of a 3-member team using MySQL, SQL, Excel, Power BI and Tableau.

The project contains customer, account, bank and transaction data. My main responsibility was working on SQL and database-related tasks, including data management, SQL queries, filtering, grouping, joins, aggregate functions and data analysis.

Key Features:
- Customer and account data management
- Banking transaction analysis
- SQL-based data analysis
- Account balance analysis
- Credit and debit transaction analysis
- Bank-wise and account-wise analysis
- Power BI interactive dashboard

Tools & Technologies:
MySQL | SQL | Microsoft Excel | Power BI | Tableau

Project Highlights:
- 3-member team project
- 500 Customers
- 500 Accounts
- 1000 Transactions
- Total Balance: ₹65,886,516.03
- Total Transaction Amount: ₹36,853,426.04

My Role:
- SQL and database-related work
- Data management and validation
- SQL queries and analysis
- Filtering, grouping, joins and aggregate functions
- Supporting dashboard preparation

This project demonstrates practical skills in SQL, database management, data analysis, Excel and Power BI.
