# \## SQL Interview Questions

# 

# \### 15. What is SQL?

# 

# SQL stands for Structured Query Language. It is used to work with data stored in relational databases.

# 

# \### 16. What is a primary key?

# 

# A primary key is a column that uniquely identifies each record in a table.

# 

# \### 17. What is a foreign key?

# 

# A foreign key is a column that connects one table with another table.

# 

# \### 18. What is a JOIN?

# 

# A JOIN is used to combine data from two or more related tables.

# 

# \### 19. What is GROUP BY?

# 

# GROUP BY is used to group rows with the same values and perform calculations on each group.

# 

# \### 20. What is HAVING?

# 

# HAVING is used to filter grouped data, usually after GROUP BY.

# 

# \### 21. What is the difference between WHERE and HAVING?

# 

# WHERE filters individual rows, while HAVING filters grouped results.

# 

# \### 22. What aggregate functions did you use?

# 

# I used COUNT, SUM and AVG for data analysis.

# 

# \### 23. Give an example of SQL analysis from your project.

# 

# I used SQL to calculate the number of accounts by account type and the total balance for each account type.

# 

# \### 24. How did you validate your data?

# 

# I checked record counts, duplicate records, NULL values and summary results using SQL and compared them with the analysis in Excel and Power BI.
